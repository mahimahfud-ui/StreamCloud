# TV Apps Downloads

Upload Android TV / Google TV / Fire TV app installers here (APK/APKS/XAPK).

Suggested filename:
`AppName-v1.2.3.apk`

After upload, use this raw URL pattern in the matching StreamCloud listing:
`https://raw.githubusercontent.com/mahimahfud-ui/StreamCloud/main/downloads/TV%20Apps/<FileName>`

Replace `<FileName>` with the exact uploaded filename.
