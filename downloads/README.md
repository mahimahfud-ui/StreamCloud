# StreamCloud Downloads

Upload your own app installer files into the matching category folder:

- [Movie Apps](./Movie%20Apps/)
- [Music Apps](./Music%20Apps/)
- [TV Apps](./TV%20Apps/)

## Upload
1. Open the category folder.
2. Select **Add file → Upload files**.
3. Drag in the APK/APKS/XAPK file(s), then commit the upload to `main`.

Use clear filenames, for example `AppName-v1.2.3.apk`.

## Connect an uploaded file to the website
After uploading, copy its GitHub file path and use the raw download URL in that listing's `downloadUrl` field:

`https://raw.githubusercontent.com/mahimahfud-ui/StreamCloud/main/downloads/<Category>/<FileName>`

The placeholder parts must be replaced with the exact category folder and filename. Keep `downloadDirect: true` for a direct installer link.

Only upload files you have the right to redistribute. Check APK/XAPK files and their source before publishing them.
